# 📈 TAOQuant

> **Deterministic Risk-Analysis Dashboard for Bittensor ($TAO)**

TAOQuant is an open-source, deterministic risk-analysis dashboard engineered to bring data transparency, mathematical rigor, and risk modeling to the Bittensor ecosystem. 

Designed with a **passive-data and disclaimer-first architecture**, TAOQuant provides real-time market indicators and mathematical models for $TAO holders and validator delegates—without taking custody of funds or offering execution services.

---

## 🚀 Live Application

Access the official live dashboard here:  
👉 **https://taoquant.vercel.app/**

---

## ✨ Key Features

- **Deterministic Risk Modeling:** Objective, formula-driven risk indicators based on network activity and real-time ledger metrics.
- **Server-Side API Proxy:** Built-in proxy architecture querying the Taostats API safely without client-side exposure.
- **Privacy-Preserving:** No wallet connection required, no user tracking, and zero custody of private keys or crypto assets.
- **Fast & Responsive:** Built on Next.js and deployed on Vercel for high availability and instant responsiveness.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Deployment:** [Vercel](https://vercel.com/)
- **Data Source:** [Taostats API](https://taostats.io/)
- **Styling:** Tailwind CSS / Shadcn UI
